# Full-field vibration mode shapes from arbitrarily timed still images

**The SIgMA (Still-Image Modal Analysis) code and the measurement data described in the corresponding article will be made publicly available in this directory upon acceptance of the article.**

Code and resources for the paper *Full-field vibration mode shapes from arbitrarily timed still images* by J. Slavič and K. Zaletelj (Laboratory for Dynamics of Machines and Structures, University of Ljubljana).
